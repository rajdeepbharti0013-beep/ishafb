# Fashion Design Portfolio

Open `index.html` in a browser. It is a standalone page with its styles and editor included.

## Edit your portfolio

1. Select **Edit portfolio** in the top right.
2. Click highlighted text to change it. Click an image frame or **Upload image** to choose a photo. Use **Remove image**, **Crop / zoom**, and the horizontal and vertical alignment sliders to adjust it.
3. Use **+ Project**, **+ Event**, or **+ Photo** to create as many entries as you need. The × controls remove entries. In an entry detail page, use **+ Add another image** for project and event process photos.
4. Open a card with **Open details** to edit its description and information on its own detail page. Use **Edit links** to update email and social destinations.
5. Select **Download copy** to save a new, standalone `fashion-portfolio.html` with your text, entries, photos, crop, and alignment included.

Your edits stay in the open page until you download a copy. Open the downloaded copy to continue editing later. No build step is required.
